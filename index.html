modde

A cross-platform game mod manager

Install Wabbajack modlists, Nexus Collections, and individual mods with a clean game directory on Linux, macOS, and Windows.

By Caniko

InstallDocs

Cross-platform

First-class on Linux, macOS, and Windows. The CLI and desktop app run natively on every platform.

Wabbajack on any OS

Parse and install .wabbajack modlists natively without a Windows VM.

Nexus integration

Browse, search, and download from Nexus Mods; pin Nexus Collections by version.

VFS deployment

A virtual filesystem keeps your game directory pristine while mods overlay cleanly.

Conflict detection

Graph-based mod conflict analysis makes file collisions visible before deploy.

Crash-log correlation

Local Crash Logger SSE and Trainwreck logs can be mapped back to the managed profile, versions, installed files, and load order.

Save vaults

Git-backed save snapshots with history, restore, and compatibility warnings.

Profile experiments

Try mod changes non-destructively, then rollback or commit when done.

Declarative with Nix

Optional Home Manager integration declares reproducible mod profiles as code.
